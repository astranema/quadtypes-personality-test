# Quadtypes Personality Test
Take the test here! https://astranema.github.io/quadtypes-personality-test/

A personality test written in vanilla JS/CSS/HTML. Calculates a person's score on four different scales (Curiosity, Sociability, Efficacy, and Prosociality).

<img width="620" height="502" alt="image" src="https://github.com/user-attachments/assets/4cebe60f-96bf-4e7a-a3c5-034d193c6a53" />

Utilizes a custom radio created using DOM manipulation in JavaScript. Buttons are labelled using ARIA to allow users using screen-reading technologies to view the site. Upon completion of the test, users are sent to a separate results page which gives them a personality type in accordance with their highest and lowest score on the four scales.
